# அணிந்துரை கோரிக்கை — பதில் வந்த பின் அனுப்ப வேண்டிய WhatsApp செய்தி

நூல்: AI அலை: நீங்கள் தயாரா? தமிழில் 300+ செய்யறிவுக் கலைச்சொற்கள்

## WhatsApp செய்தி (நகல் எடுத்து ஒட்டவும்)

```
Vijay Krishnan அவர்களே, *அணிந்துரை, வாழ்த்துரை, சிறப்புரை* எழுதத் தயாராக முன்வந்தமைக்கு என் மனமார்ந்த நன்றி. உங்கள் ஆதரவு இந்த முயற்சிக்குப் பெருமிதம்.

நூலின் முழு வரைவை epub வடிவத்தில் இங்கே பார்க்கலாம்:
https://github.com/kpassoubady/tamil-glossary/blob/main/book/builder/pdf/Tamil-AI-Glossary-v3.epub 

வசதியான இடத்தில் உங்கள் கணினியில் பதிவிறக்கம் செய்து படித்துப் பாருங்கள். புத்தகத்தைப் பற்றி வேறு ஏதேனும் கருத்துகள் இருந்தாலும் தெரிவிக்கவும். உங்களுக்கு docx, epub வடிவத்திலும் அனுப்பி வைக்க இயலும், தேவைப்பட்டால் சொல்லுங்கள்.

மீண்டும் நன்றி.

அன்புடன்,
காங்கேயன் பசுபதி
```

## குறிப்புகள்

- `[பெயர்]` இடத்தில் பதில் அளித்தவரின் பெயரைச் சேர்க்கவும்.
- WhatsApp இல் ஒட்டும்போது, மேற்கோள் குறிகள் (```) நீக்கிவிட்டு உள்ளே உள்ள உரையை மட்டும் ஒட்டவும். *தடித்த எழுத்து* குறியீடுகள் WhatsApp இல் தானாகத் தடித்த எழுத்தாகக் காட்டப்படும்.

## திருத்தப்பட்ட WhatsApp செய்தி

```
[பெயர்] அவர்களே,

*அணிந்துரை, வாழ்த்துரை, சிறப்புரை* எழுதத் தயாராக முன்வந்தமைக்கு என் மனமார்ந்த நன்றி. உங்கள் ஆதரவு தமிழுக்குப் பெருமை சேர்ப்பது.

நூலின் முழு வரைவு இங்கே:
https://github.com/kpassoubady/tamil-glossary/blob/main/book/builder/pdf/Tamil-AI-Glossary-v3.pdf

வசதியாக உங்கள் கணினியில் பதிவிறக்கம் செய்து படித்துப் பாருங்கள். புத்தகத்தைப் பற்றி வேறு ஏதேனும் கருத்துகள் இருந்தாலும் தெரிவிக்கவும். docx, epub வடிவங்களிலும் அனுப்ப இயலும்; தேவையெனில் தெரிவியுங்கள்.

மீண்டும் நன்றி.

அன்புடன்,
காங்கேயன் பசுபதி
```

### முக்கிய திருத்தங்கள்

1. "தமிழ் ஆர்வலரே:" → `[பெயர்] அவர்களே,` — குறிப்பிட்ட நபருக்கு அனுப்பும்போது பெயர் சேர்ப்பது இயல்பு.
2. "உங்கள் ஆதரவுக்கு தமிழுக்கான பெருமிதம்" → "உங்கள் ஆதரவு தமிழுக்குப் பெருமை சேர்ப்பது" — வாக்கிய அமைப்பு தெளிவாகிறது.
3. "நூலின் முழு வரைவை இங்கே பார்க்கலாம்" → "நூலின் முழு வரைவு இங்கே" — சுருக்கமாகவும் இயல்பாகவும் உள்ளது.
4. "வசதியான இடத்தில்" → "வசதியாக" — தேவையற்ற இடக்குறிப்பை நீக்கியுள்ளேன்.
5. "உங்களுக்கு docx, epub வடிவத்திலும் அனுப்பி வைக்க இயலும், தேவைப்பட்டால் சொல்லுங்கள்" → "docx, epub வடிவங்களிலும் அனுப்ப இயலும்; தேவையெனில் தெரிவியுங்கள்" — மரியாதையான வினைமுற்று மற்றும் சுருக்கம்.
